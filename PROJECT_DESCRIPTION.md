## Student Marks Calculator

## About the Project

The Student Marks Calculator is a C programming project developed to calculate and evaluate a student's academic performance.

The program accepts the student's name and marks in five subjects and calculates the total marks, percentage, and grade.

## Features

- Accepts student name.
- Takes marks in five subjects.
- Calculates total marks out of 500.
- Calculates percentage.
- Assigns grades based on percentage.
- Uses dynamic memory allocation.
- Implements file handling.

## Grading System

Percentage| Grade
90% and above| A+
75% to 89%| A
60% to 74%| B
40% to 59%| C
Below 40%| F
